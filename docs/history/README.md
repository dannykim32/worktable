# History

The project's paper trail, kept for the record. None of this describes the current
product - for that, read the top-level `README.md`, `CONTEXT.md`, and `docs/adr/`.

- **`v1-tracker/`** - the original PRD and the numbered issue specs (01-27) the v1
  build ran on, including the features later retired in ADR-0012 (the structured
  component vocabulary, the SVG legibility gate). Written under the project's original
  name, `visual-chat`.
- **`qa/`** - QA evidence from the retired renderers: the six legibility-gate
  calibration rounds and the M1/M2 screenshots.
- **`prototypes/`** - throwaway prototypes whose conclusions were folded into ADRs:
  `canvas-vocabulary/` (the judged component-vocabulary mock) and `warm-palette/` (the
  abandoned warm identity, replaced by "Slate").
